VS CODE REMOTE-SSH — HOW TO USE (EMR CLUSTER WORKFLOW)
One-time setup (per laptop):

Install the "Remote - SSH" extension in VS Code (publisher: Microsoft).
Add an entry to ~/.ssh/config on your laptop:

Host emr-master
    HostName <EMR_MASTER_PUBLIC_IP>
    User hadoop
    IdentityFile <PATH_TO_YOUR_PEM>
    IdentitiesOnly yes

Lock down permissions:

chmod 400 <path-to-pem>
chmod 600 ~/.ssh/config

Test with plain SSH first: ssh emr-master

Every time you launch a new EMR cluster (master IP changes unless you use an Elastic IP):

Update the HostName in ~/.ssh/config to the new public IP.

Connecting from VS Code:

Command Palette (Ctrl+Shift+P / Cmd+Shift+P) → "Remote-SSH: Connect to Host..." → select emr-master.
A new VS Code window opens, connects over SSH, installs the VS Code Server on the master (first time only, then cached).
File → Open Folder → point to your project directory on the master (e.g. /home/hadoop/<repo-name>).


Git workflow (how code moves between master and your laptop/GitHub):

On the master (first time only, if git isn't installed): sudo yum install -y git
Set identity (first time only, or after a fresh cluster):

git config --global user.name "Your Name"
git config --global user.email "your@email.com"

Clone your repo (first time on a new cluster):

git clone https://github.com/<username>/<repo>.git
When prompted: username = GitHub username, password = your PAT (works for private repos too, as long as it has repo scope).
